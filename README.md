# Student Performance Analysis – Data Science Mini Project

## About the Project
This project focuses on analysing student academic performance using Python and Data Science techniques.

The Student Performance dataset is used to explore the relationship between students' study habits, attendance, previous grades, and final academic performance.

## Objectives
- Analyze a real-world dataset.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Identify meaningful patterns and insights.
- Create visualizations to understand student performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset
Student Performance Dataset (Portuguese Language)

- Total Records: 649
- Total Features: 33
- File Format: CSV

## Analysis Performed
1. Dataset exploration
2. Data cleaning
3. Missing value analysis
4. Duplicate detection
5. Student grade analysis
6. Study time analysis
7. Gender distribution
8. Absences analysis
9. Correlation analysis

## Visualizations
- Final Grade Distribution
- Study Time vs Final Grade
- Gender Distribution
- Absences vs Final Grade
- Correlation Heatmap

## Key Outcomes
The project explores academic performance patterns and relationships between student characteristics, study habits, attendance, and final grades.

## Conclusion
This mini project provided practical experience in Python-based data analysis, data visualization, and extracting meaningful insights from real-world datasets.
